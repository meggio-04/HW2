A reproducible PyTorch / scikit-learn pipeline that compares three ways of reusing an ImageNet-pretrained **MobileNetV3-Small** (`MobileNet_V3_Small_Weights.DEFAULT`) on the **Oxford-IIIT Pet** dataset (37 cat and dog breeds). All three methods use the same splits, preprocessing and evaluation metrics; the test set is used only once per selected model.

---

## Compared Methods

1. **Full fine-tuning**: the final layer is replaced by `Linear(1024, 37)` and the whole network is trained (1,555,781 trainable parameters).
2. **Classifier-head training**: same replacement, `features` frozen (kept in eval mode); trainable layers are `classifier[0]` Linear(576→1024) and `classifier[3]` Linear(1024→37) (628,773 parameters).
3. **Feature extraction + linear SVM**: the whole network is frozen, the 576-d vector after global average pooling is extracted once and a `StandardScaler` + `LinearSVC` pipeline is trained with scikit-learn (0 trainable CNN parameters, 21,349 SVM parameters). The scaler is fitted on the training features only.

> **Note:** model selection (best epoch for methods 1–2, best `C` for method 3) uses the validation macro F1 only. The test set is never used for training, early stopping or tuning.

## Execution

Run the script **from the repository root**, because all paths are relative:

```bash
python imageClassification.py
```

The script downloads the dataset to `./data` (through `torchvision.datasets.OxfordIIITPet`), creates the stratified train/validation split, trains methods 1 and 2, extracts features and fits the SVMs for method 3, evaluates the three selected models on the test set and writes checkpoints, confusion matrices, prediction examples and CSV files to `./results/`. Everything is generated by this single command.

## Parameters

Constants defined in `imageClassification.py` and `funzioni.py` (identical for all methods unless stated):

| Parameter | Value | Description |
|---|---|---|
| `SEED` | 42 | Seed for `random`, NumPy, PyTorch, the data split, the shuffling generator and `LinearSVC` |
| `test_size` | 0.20 | Validation share of the official trainval split (stratified by breed) |
| `BATCH_SIZE` | 32 | Batch size (methods 1–2) |
| `NUM_EPOCHS` | 15 | Epochs (methods 1–2) |
| `LEARNING_RATE` | 1e-4 | Adam, no scheduler, no weight decay (methods 1–2) |
| Loss | cross-entropy | Methods 1–2 |
| `C` grid | 0.001, 0.01, 0.1, 1, 10, 100 | `LinearSVC` (squared hinge, one-vs-rest, `dual=False`, `tol=1e-3`, `max_iter=10000`) |

**Preprocessing:** validation and test images use `weights.transforms()` (resize 256, center crop 224, ImageNet mean/std). Training images (methods 1–2) use `RandomResizedCrop(224, scale=(0.8, 1.0))`, horizontal flip (p = 0.5) and the same normalization. The SVM is trained on features of the non-augmented training images. No class balancing is applied (weights or resampling): the dataset is almost balanced.

**Selected checkpoints:** full fine-tuning epoch 14, classifier-head epoch 15, SVM `C = 0.01`. The checkpoints of methods 1–2 contain epoch, validation scores, learning rate, batch size and seed. The SVM is refitted in a few seconds, so it is not saved.

## Reproducibility

- Seed 42 is set for Python, NumPy and PyTorch (`set_seed` in `funzioni.py`); the shuffling of the training `DataLoader` uses a generator with a fixed seed, reset before each method.
- `torch.backends.cudnn.deterministic = True`, `cudnn.benchmark = False` and `torch.use_deterministic_algorithms(True, warn_only=True)` are enabled. `CUBLAS_WORKSPACE_CONFIG=":4096:8"` is set at the start of the script when a GPU is available, before any CUDA operation. No determinism warning appeared in the console log of the reported run.
- **Remaining sources of variation:** exact numbers may differ across GPUs, CUDA/cuDNN and library versions. Each result is a single run with one seed.
- **Splits:** no split file is stored; the partition is fully determined by the official trainval list and `train_test_split(..., test_size=0.20, random_state=42, stratify=labels)`. The resulting per-breed counts are saved in `results/class_counts.csv`.
- **Hardware of the reported run:** NVIDIA Quadro T1000 with Max-Q (GPU).
- **Timing:** the times of methods 1–2 include validation and checkpoint saving at every epoch; the time of method 3 includes train and validation feature extraction and all six SVM fits, not the test features.

## Dataset Information

The **Oxford-IIIT Pet Dataset** (37 breeds, 25 dogs and 12 cats; official trainval: 3,680 images, test: 3,669 images) is obtained from the Visual Geometry Group, University of Oxford: <https://www.robots.ox.ac.uk/~vgg/data/pets/>. It is distributed under the **Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)** license. The images are not redistributed in this repository: `torchvision.datasets.OxfordIIITPet(root="./data", download=True)` downloads them automatically the first time the script is run.

**Citation:** O. M. Parkhi, A. Vedaldi, A. Zisserman, C. V. Jawahar, "Cats and Dogs", *IEEE Conference on Computer Vision and Pattern Recognition (CVPR)*, 2012.

**Pre-trained weights:** `MobileNet_V3_Small_Weights.DEFAULT` (ImageNet-1K) from TorchVision.
